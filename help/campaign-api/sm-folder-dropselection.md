# Auswahl ablegen

Verschiebt die Auswahl in einen Knoten des Navigationsbaums

```text
DropSelection ( String schema, String entityFolder, XML selectionList, Number folderDestId )
```

## Parameter

**schema** Auswahlschema-ID

**entityFolder**-ID des Zielordners

**selectionList** Zu verschiebende Auswahl

**folderDestId** Zielordner

## Rückgabewert(e)

Keine.

## Funktionen

**Schema:** [xtk:folder](s-xtk-folder.md)

**static:**

Ja
