# Richtlinienseite

Enthält eine Bibliothek mit Funktionen oder Zeichenfolgen.

## Syntax

&lt;%@ page import=„lib1, …“ %> &lt;%@ page stringGroup=„groupName“ %>

## Beschreibung

Beim Importieren einer Zeichenfolgenbibliothek wird ein globales JavaScript-Objekt angezeigt, dessen Name mit sg\_ beginnt, gefolgt vom Namen der Bibliothek, deren Sonderzeichen durch &quot;\_“ ersetzt wurden. Wenn Sie beispielsweise nms einschließen:campaign wird die Variable sg\_nms\_campaign erstellt.

## Beispiel

```xml
      <%@ page import="xtk:shared/nl.js,nms:campaign.js" %>
<%@ page stringGroup="nms:campaign" %>
...
<%= sg_nms_campaign.stateLabel() %>
...
```
