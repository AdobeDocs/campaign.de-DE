# SaveUrlInfo

Speichert die URLs dieses Versands als URL-Vorlagen.

```text
SaveUrlInfo ( XML insUrlList, XML updUrlList )
```

## Parameter

**insUrlList** Liste der neuen URLs (die keiner URL-Vorlage zugeordnet sind)

**updUrlList** Liste der zu aktualisierenden URL-Vorlagen

## Rückgabewert(e)

Keine.

## Funktionen

**Schema:** [nms:delivery](s-nms-delivery.md)

**static:**

Ja
