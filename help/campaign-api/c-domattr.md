# DOMAttr (Klasse)

Ein Attributtyp-Knoten.

## Eigenschaften

| Eigenschaft | Beschreibung |
| --- | --- |
| [isId](p-domattr-isid.md) | true, wenn das Attribut ein ID-Typ ist. |
| [name](p-domattr-name.md) | Attributname. |
| [ownerElement](p-domattr-ownerelement.md) | Das Element mit diesem Attribut oder null. |
| [angegeben](p-domattr-specified.md) | true, wenn der Wert explizit angegeben ist (dies ist standardmäßig kein impliziter Wert). |
| [value](p-domattr-value.md) | Attributtextwert. |
