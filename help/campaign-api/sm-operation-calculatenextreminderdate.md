# calculateNextReminderDate

Berechnet das nächste Erinnerungsdatum (wenn leer, keine Erinnerung)

```text
Date parentOut = CalculateNextReminderDate ( Date lastReminderDate, Date expectedDate, XML parameter )
```

## Parameter

**lastReminderDate** Datum der letzten Erinnerung

**expectedDate** Genehmigungsdatum

**parameter** Konfiguration

## Rückgabewert(e)

**parentOut** Ergebnis
