# HasWarning

Fragt ab, ob für einen Auftrag Warnhinweise oder Fehler erzeugt wurden.

```text
Boolean hasWarning = HasWarning ( String id )
```

## Parameter

**id** Auftragskennung

## Rückgabewert(e)

**hasWarning** Gibt „true“ zurück, wenn mindestens ein Warnhinweis oder eine Fehlermeldung ausgegeben wurde

## Funktionen

**Schema:** [xtk:job](s-xtk-job.md)

**static:**

Ja
