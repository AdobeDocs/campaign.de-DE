# createProcessingInstruction

Erstellt eine neue Verarbeitungsanweisung.

```text
createProcessingInstruction (target, data)
```

## Parameter

**target** Verarbeitungsanweisung target, z. B. &lt;?php … ?>.

**data** Zeichenfolge, die in die Anweisung eingefügt werden soll.

## Rückgabewert

[processingInstruction](c-domnode.md) erstellt.
