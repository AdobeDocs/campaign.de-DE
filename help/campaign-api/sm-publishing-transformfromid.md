# TransformFromId

Veröffentlichungsumwandlung ausgehend von einer Inhalts-ID

```text
[ String format, String result ] = TransformFromId ( String publishingId, String modelName, String contentId )
```

## Parameter

**publishingId** Kennung der Veröffentlichungsvorlage

**modelName** Name der Umwandlungsvorlage

**contentId** Inhaltskennung

## Rückgabewert(e)

**format** Ausgabeformat

**result** Umwandlungsergebnis

**Schema:** [ncm:publishing](s-ncm-publishing.md)

Ja
