# Transitionen

Gibt die Liste der Transitionen der Aktivität aus

```text
transitions ()
```

## Parameter

Keine.

## Rückgabewert

Eine Tabelle, die alle Transitionen der Aktivität in der Reihenfolge enthält, in der sie definiert sind.

**Methode der Klasse:** [WorkflowTask](c-workflowtask.md)
