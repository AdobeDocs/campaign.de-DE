# SchemaKey (Klasse)

Stellt die Definition eines Schlüssels dar.

## Eigenschaften

| Eigenschaft | Beschreibung |
| --- | --- |
| [label](p-schemakey-label.md) | Gibt die Kurzbeschreibung des Schlüssels zurück. |
| [description](p-schemakey-description.md) | Gibt die Beschreibung des Schlüssels zurück. |
| [name](p-schemakey-name.md) | Gibt die Kennung des Schlüssels aus |
| [isInternal](p-schemakey-isinternal.md) | Gibt „true“ zurück, wenn der Schlüssel der interne Schlüssel ist. |
| [allowEmptyPart](p-schemakey-allowemptypart.md) | Gibt „true“ zurück, wenn Felder des Schlüssels leer sein können (mindestens eines der Felder muss eingegeben werden). |
| [Felder](p-schemakey-fields.md) | Gibt eine Tabelle zurück, die das Feld der Felder ( [SchemaNode](c-schemanode.md) ) des Schlüssels enthält. |

## Funktionen

**Verfügbar in:**

* Content-Management
* Versandeigenschaften
* Typologieregel
* JSSP
* SOAP-Methoden
* WebApp
* Workflow
