# HttpServletResponse (Klasse)

Stellt die Antwort eines Servlets dar, das an einen Client zurückgegeben wird.

Es gibt nur eine Instanz dieser Klasse, auf die über die `response` zugegriffen werden kann.

## Methoden

| Methode | Beschreibung |
| --- | --- |
| [setContentType](m-httpservletresponse-setcontenttype.md) | Ändert den Dokumenttyp der Antwort. |
| [sendRedirect](m-httpservletresponse-sendredirect.md) | Gibt eine temporäre Umleitung zu einer anderen URL zurück. |
| [addCookie](m-httpservletresponse-addcookie.md) | Fügt der Antwort ein Cookie hinzu. |
| [addHeader](m-httpservletresponse-addheader.md) | Fügt der Antwort einen zusätzlichen HTTP-Header hinzu. |
| [sendError](m-httpservletresponse-senderror.md) | Gibt eine Fehlerantwort mit dem als Parameter übergebenen Fehlercode zurück. |

## Funktionen

**Verfügbar in:**

* JSSP
* WEBAPP
