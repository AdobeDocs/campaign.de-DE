# Testkonto

Führt einen Verbindungstest durch

```text
TestAccount ( Number type, String server, String account, String password, String port, String options )
```

## Parameter

**type** Kontotyp

**server** Server-Adresse

**Konto** Name (oder Login) des Kontos

**Kennwort** Passwort des Kontos

**port** Server-Port

**options** Verbindungsoptionen

## Rückgabewert(e)

Keine.

## Funktionen

**Schema:** [nms:extAccount](s-nms-extaccount.md)

**static:**

Ja
