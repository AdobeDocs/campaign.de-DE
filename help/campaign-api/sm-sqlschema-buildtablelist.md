# BuildTableList

Erstellt eine Liste mit Tabellennamen

```text
XML tableList = BuildTableList ( String dataSource, String tablePattern )
```

## Parameter

**dataSource** ID der Datenquelle

**tablePattern** Maske für den Tabellennamen

## Rückgabewert(e)

**tableList** Listen vorhandener Tabellen

## Funktionen

**Schema:** [xtk:sqlSchema](s-xtk-sqlschema.md)

**static:**

Ja
