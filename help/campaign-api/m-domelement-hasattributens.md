# hasAttributeNS

Testet das Vorhandensein eines Attributs.

```text
hasAttributeNS (namespaceURI, localName)
```

## Parameter

**namespaceURI** URI des Attribut-Namespace.

**localName** Attributname.

## Rückgabewert

true, wenn das Attribut vorhanden ist, andernfalls false.
