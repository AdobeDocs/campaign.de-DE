# RegisterTransientSchema

Speichert ein Schema im Zusammenhang mit dem Ergebnis einer Abfrage

```text
RegisterTransientSchema ( String name, String label, String sqltable, XML query )
```

## Parameter

**name** Schemaname

**label** Schemakennzeichnung

**sqltable** SQL-Name der Tabelle

**query** Abfragedefinition

## Rückgabewert(e)

Keine.

## Funktionen

**Schema:** [xtk:report](s-xtk-report.md)

**static:**

Ja
