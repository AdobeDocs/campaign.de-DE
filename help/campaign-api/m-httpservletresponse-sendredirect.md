# sendRedirect

Gibt eine temporäre Umleitung zu einer anderen URL zurück.

```text
sendRedirect (location)
```

## Parameter

**location** Umleitungs-URL.

## Rückgabewert

Keine.

## Funktionen

**Methode der Klasse:** [HttpServletResponse](c-httpservletresponse.md)

**Verfügbar in:**

* JSSP
* WEBAPP
