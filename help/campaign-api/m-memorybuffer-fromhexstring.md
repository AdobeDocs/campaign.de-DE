# fromHexString

Lädt den Inhalt einer hexadezimalen Zeichenfolge in den Puffer.

```text
fromHexString (string)
```

## Parameter

**string** Eine Zeichenfolge, die die im Hexadezimalsystem kodierten Binärdaten darstellt, die dem Puffer hinzugefügt werden sollen.

## Rückgabewert

Keine.
