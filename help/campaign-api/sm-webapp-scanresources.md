# Ressourcen durchsuchen

Sucht zu übersetzende Ressourcen in einer Web-Anwendung.

```text
XML resources = ScanResources ( XML webApp )
```

## Parameter

**webApp** Definition der Webanwendung.

## Rückgabewert(e)

**resources** Zu übersetzende Ressourcen.

## Funktionen

**Schema:** [nms:webApp](s-nms-webapp.md)

**static:**

Ja
