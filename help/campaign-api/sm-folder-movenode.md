# Knoten verschieben

Verschiebt einen Knoten im Navigationsbaum

```text
MoveNode ( String key, String parentKey, Number order, String fullName )
```

## Parameter

**key** Knotenschlüssel

**parentKey** Übergeordneter Schlüssel

**order** Neuer Knotenindex

**fullName** Vollständiger Name (nicht leer, um das übergeordnete Element in der Struktur zu ändern)

## Rückgabewert(e)

Keine.

## Funktionen

**Schema:** [xtk:folder](s-xtk-folder.md)

**static:**

Ja
