# generateFromId

Erzeugt und veröffentlicht basierend auf einem Verzeichnis einen Inhalt von seiner Kennung ausgehend

```text
String outputFiles = GenerateFromId ( String id, String publishingDir )
```

## Parameter

**id** Inhaltskennung

**publishingDir** Veröffentlichungsordner

## Rückgabewert(e)

**outputFiles** Liste der erzeugten Dateien

## Funktionen

**Schema:** [ncm:publishing](s-ncm-publishing.md)

**static:**

Ja
