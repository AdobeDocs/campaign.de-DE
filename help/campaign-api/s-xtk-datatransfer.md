# Datenübertragung

Scripts für die Datenübertragung (Import/Export)

## Methoden

| Methode | Beschreibung |
| --- | --- |
| [AutoDetect](sm-datatransfer-autodetect.md) | Startet eine Auto-Discovery und gibt die ersten Zeilen der Datei aus |
| [Bereinigung](sm-datatransfer-cleanup.md) | Löscht den Verlauf der Ausführungsinstanz |
| [ExportPreview](sm-datatransfer-exportpreview.md) | Erstellt eine Vorschau der Spalten der Ausgabedatei für die ersten Zeilen der Abfrage |
| [GetFilesToDownload](sm-datatransfer-getfilestodownload.md) | Auflistung der auf dem Server befindlichen Dateien für diese Übertragung |
| [RejectExport](sm-datatransfer-rejectexport.md) | Startet den Export der Zurückweisungen |
| [Starten](sm-datatransfer-start.md) | Startet die Datenübertragung |
| [TestCalcField](sm-datatransfer-testcalcfield.md) | Testet das berechnete Feld für Beispielzeilen |

## Generische Methoden

| Methode | Beschreibung |

| [Erstellen](f-create.md) | Erstellt eine neue Entität, die einem bestimmten Schema entspricht. |
| [LOAD](f-load.md) | Lädt eine Entität, die einem bestimmten Schema und Schlüssel entspricht, und gibt sie zurück. |
