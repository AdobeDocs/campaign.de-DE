# GetDescriptiveAnalysisData

Führt die Datenabfrage einer deskriptiven Analyse aus

```text
XML data = GetDescriptiveAnalysisData ( XML entity, XML context )
```

## Parameter

**entity** XML-Dokument, das das Diagramm beschreibt

**context** XML-Kontext zum Filtern der Daten

## Rückgabewert(e)

**data** Daten im XML-Format

## Funktionen

**Schema:** [xtk:report](s-xtk-report.md)

**static:**

Ja
