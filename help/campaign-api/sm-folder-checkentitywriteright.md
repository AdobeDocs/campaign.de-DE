# CheckEntityWriteRight

Gibt &#39;TRUE&#39; aus, wenn der aktuelle Benutzer auf eine bestimmte Entität Schreibzugriff hat

```text
Boolean result = CheckEntityWriteRight ( String schema, String key )
```

## Parameter

**schema** Kennung des Entitätsschemas

**key** Wert des Primärschlüssels der Entität

## Rückgabewert(e)

**result** Result

## Funktionen

**Schema:** [xtk:folder](s-xtk-folder.md)

**static:**

Ja
