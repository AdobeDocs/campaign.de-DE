# hasElement

Prüft, ob das Element über ein untergeordnetes Element verfügt, indem es die angegebenen Kriterien überprüft.

```text
hasElement (tagName [, attrName ] [, attrValue ])
```

## Parameter

**tagName** Name des durchsuchten Elements.

**attrName** Name eines Attributs, das einen bestimmten Wert überprüfen muss.

**attrValue** Attributwert.

## Rückgabewert

true, wenn das Element ein untergeordnetes Element aufweist, indem die angegebenen Daten überprüft werden, andernfalls false.
