# GetNewIds

Erstellt eine Liste mit Kennungen der internen Schlüssel der Datenbank

```text
String idList = GetNewIds ( Number count )
```

## Parameter

**count** Anzahl der Kennungen, die diese Methode zurückgeben soll

## Rückgabewert(e)

**idList** Durch Kommas getrennte Liste von Bezeichnern

## Funktionen

**Schema:** [xtk:session](s-xtk-session.md)

**static:**

Ja
