# Auswahl verschieben

Verschiebt die Auswahl in einen Knoten des Navigationsbaums

```text
MoveSelection ( String schemaId, String entityFolder, XML selectionList, String key )
```

## Parameter

**schemaId** ID des Auswahlschemas

**entityFolder**-ID des Zielordners

**selectionList** Zu verschiebende Auswahl

**key** Knotenschlüssel

## Rückgabewert(e)

Keine.

## Funktionen

**Schema:** [xtk:folder](s-xtk-folder.md)

**static:**

Ja
