# NotifyValidation

Benachrichtigt von der Validierung innerhalb einer Kampagne.

```text
NotifyValidation ( Number deliveryId, Boolean target, Boolean content, Boolean budget, Boolean extraction, Boolean FCP, Boolean sandbox, Boolean edition, Boolean external )
```

## Parameter

**deliveryId** Versandkennung

**target** Zielgruppenvalidierung

**content** Inhaltsvalidierung

**budget** Budgetvalidierung

**Extraktion** Validierung der Extraktionsdatei

**FCP** Testversand-Genehmigung

**Sandbox** Validierung der Zielgruppenschätzung

**edition** Inhaltsbearbeitung

**extern** Externe Inhaltsvalidierung

## Rückgabewert(e)

Keine.

**Schema:** [nms:operation](s-nms-operation.md)

**static:**

Ja
