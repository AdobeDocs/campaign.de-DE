Aktualisiert eine Schematasammlung ausgehend von ihrer physischen Darstellung in der Datenbank.

```text

```

**schema** Zu regenerierendes Schema

## Rückgabewert(e)

**result** Erzeugtes Schema

**Warnung** Warnung
