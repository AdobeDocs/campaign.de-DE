# JavaScript-Vorlage auswerten

Auswertung eines JavaScript-Templates (JST)

```text
[ XML context, String result ] = EvaluateJavaScriptTemplate ( String name, String template, XML context )
```

## Parameter

**name** Skriptname.

**template** Dokument zur Auswertung.

**context** Kontext bei der Auswertung des Dokuments.

## Rückgabewert(e)

**context** Kontext bei der Auswertung des Dokuments.

**Ergebnis** Dokument, das aus der Auswertung hervorgeht.

**Schema:** [xtk:builder](s-xtk-builder.md)
