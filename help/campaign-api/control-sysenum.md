# SysEnum

Mit diesem Steuerelement können Sie einen Wert aus einer Systemaufzählung auswählen.

![SysEnum-Steuerelement](assets/sysenum.1eccf324.png)

## Eigenschaften

**backColor - Zeichenfolge** Hintergrundfarbe (btnshadow, weiß).

**border - string** Ändert den Stil des Kontrollentwurfs (solid, double, inset, outset, none).

**defaultIfInvalid - Zeichenfolge** Wert, der bei einem ungültigen Wert verwendet wird.

**enum - Zeichenfolge** Zu verwendende Auflistung.

**font-size - integer** Ändert die Schriftgröße.

**label - Zeichenfolge** Zugeordnete Bezeichnung.

**noInvalidErr - boolean** Zeigt keinen Fehler an, wenn der Wert ungültig ist.

**nolabel - Boolesch** Blendet die zugehörige Beschriftung aus.

**readOnly - boolean** Erzwingt, dass das Steuerelement schreibgeschützt ist.

**erforderlich - boolesch** Das Feld ist obligatorisch.

**serialize - boolean** Speichert den zuletzt ausgewählten Wert.

**useDesc - Boolesch** Zeigt die Beschreibung und nicht die Beschriftung an.

**xpathEnum - xpath** Verwendet den von diesem XPath referenzierten Wert anstelle der Enum-Eigenschaft für die Auflistung.
