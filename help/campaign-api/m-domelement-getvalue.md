# getValue

Gibt den Knotenwert zurück, der vom angegebenen XPath referenziert wird.

```text
getValue (xpath)
```

## Parameter

**xpath** Pfad.

## Rückgabewert

Textwert des referenzierten Knotens.

## Bemerkungen

Die Syntax für den XPath akzeptiert nur eine XPath-Sprachuntergruppe. Wenn der Pfad fehlerhaft ist, wird eine Ausnahme ausgelöst.
