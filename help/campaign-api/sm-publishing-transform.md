# Transform

Veröffentlichungsumwandlung von einem Inhalt ausgehend

```text
[ String format, String result ] = Transform ( String publishingId, String modelName, XML content )
```

## Parameter

**publishingId** Kennung der Veröffentlichungsvorlage

**modelName** Name der Umwandlungsvorlage

**content** Zu transformierende Inhaltsdaten

## Rückgabewert(e)

**format** Ausgabeformat

**result** Umwandlungsergebnis

## Funktionen

**Schema:** [ncm:publishing](s-ncm-publishing.md)

**static:**

Ja
