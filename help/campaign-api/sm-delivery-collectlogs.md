# Protokolle erfassen

Erstellt eine Tabelle mit sämtlichen Versandlogs einer Versandliste

```text
CollectLogs ( Number id, XML deliveries, String logTable )
```

## Parameter

**id** Eindeutige Prioritätskennung

**Sendungen** Liste der zu berücksichtigenden Sendungen

**logTable** zu erstellende Tabelle, die alle Protokollmeldungen enthält

## Rückgabewert(e)

Keine.

## Funktionen

**Schema:** [nms:delivery](s-nms-delivery.md)

**static:**

Ja
