# GetRcpIdFromConnectionString

Gibt die Kennung eines Empfängers in Abhängigkeit von seinem Verbindungs-String aus.

```text
[ String id, String cryptedId ] = GetRcpIdFromConnectionString ( String connectionString )
```

## Parameter

**connectionString** Verbindungszeichenfolge

## Rückgabewert(e)

**id** Externe Kennung

**cryptedId** Verschlüsselte Kennung

## Funktionen

**Schema:** [nms:webForm](s-nms-webform.md)

**static:**

Ja
