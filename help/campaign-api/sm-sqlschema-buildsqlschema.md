# BuildSqlSchema

Erzeugt den Code eines Schemas basierend auf der physischen Struktur der Tabelle, die im Parameter bezeichnet wird.

```text
XML schema = BuildSqlSchema ( String dataSource, String tableName )
```

## Parameter

**dataSource** ID der Datenquelle

**tableName** Tabellenname

## Rückgabewert(e)

**schema** Erzeugtes Schema

## Funktionen

**Schema:** [xtk:sqlSchema](s-xtk-sqlschema.md)

**static:**

Ja
