# Konflikt

> Warnung: Diese Funktion ist für eine On-Premise-Umgebung verfügbar.

Temporäre Speicherung der Entitäten mit Konflikten

## Methoden

| Methode | Beschreibung |
| --- | --- |
| [AcceptCus](sm-conflict-acceptcus.md) | Behält die aktuelle Version bei. |
| [AcceptNew](sm-conflict-acceptnew.md) | Akzeptiert die neue Version als die aktuelle Version. |
| [SetResolved](sm-conflict-setresolved.md) | Erklärt eine Entität für konfliktfrei. |

## Generische Methoden

| Methode | Beschreibung |
| --- | --- |
| [Erstellen](f-create.md) | Erstellt eine neue Entität, die einem bestimmten Schema entspricht. |
| [LOAD](f-load.md) | Lädt eine Entität, die einem bestimmten Schema und Schlüssel entspricht, und gibt sie zurück. |
| [Speichern](m-entity-save.md) | Speichert eine Entität in der Datenbank |
