Erstellt eine Objektinstanz von einer Vorlage ausgehend

```text
Number output = CreateInstanceFromModel ( String schema, Number modelId, XML diff )
```

## Parameter

**schema** Instanzschema

**modelId** ID der Vorlage

**diff** XML-Patch zum Anwenden auf die Vorlage

## Rückgabewert(e)

**Ausgabe** ID der erstellten Instanz
