# insertBefore

Fügen Sie einen Knoten vor einer bestimmten Position ein.

```text
insertBefore (newChild, refChild)
```

## Parameter

**newChild**-Knoten zum Einfügen.

**refChild** Untergeordneter Knoten, der dem einzufügenden Knoten folgen muss.

## Rückgabewert

Eingefügter Knoten
