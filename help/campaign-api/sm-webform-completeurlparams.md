# CompleteURLParams

Komplettiert eine nach einem Erfolg zurückgegebene URL

```text
String result = CompleteURLParams ( String formName, String xpathParams, XML recipient )
```

## Parameter

**formName** Formularname

**xpathParams** Kommagetrennte Liste der zurückzugebenden XPaths

**Empfänger** Empfängerdaten

## Rückgabewert(e)

**result** Gibt Parameter für die URL zurück.

## Funktionen

**Schema:** [nms:webForm](s-nms-webform.md)

**static:**

Ja
