# removeAttribute

Löschen eines Attributs.

```text
removeAttribute (name)
```

## Parameter

**name** Attributname.

## Rückgabewert

Keine.

## Bemerkungen

Die Methode hat keine Auswirkung, wenn das Element kein Attribut dieses Namens aufweist.
