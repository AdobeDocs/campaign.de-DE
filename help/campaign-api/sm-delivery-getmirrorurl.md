# GetMirrorURL

Ruft die URL einer HTML-Mirrorseite ab.

```text
String url = GetMirrorURL ( Number deliveryId, String message )
```

## Parameter

**deliveryId** Versandkennung

**message** Nachrichten-ID

## Rückgabewert(e)

**url** URL der Mirrorseite

## Funktionen

**Schema:** [nms:delivery](s-nms-delivery.md)

**static:**

Ja
