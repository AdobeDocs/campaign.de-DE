# GetDirtyCacheEntities

Gibt die im Cache enthaltenen, nicht aktualisierten Entitäten aus

```text
XML dirtyEntities = GetDirtyCacheEntities ( XML cacheEntities )
```

## Parameter

**cacheEntities** Liste der zwischengespeicherten Entitäten

## Rückgabewert(e)

**dirtyEntities** Liste der nicht aktualisierten Entitäten

## Funktionen

**Schema:** [xtk:session](s-xtk-session.md)

**static:**

Ja
