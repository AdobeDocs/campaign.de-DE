# setAttributeNS

Ändern des Werts eines Attributs oder Erstellen eines neuen Attributs.

```text
setAttributeNS (namespaceURI, qualifiedName, value)
```

## Parameter

**namespaceURI** URI des Attribut-Namespace.

**authorizedName** Qualifizierter Name des Attributs.

**value** Attributtextwert.

## Rückgabewert

Keine.
