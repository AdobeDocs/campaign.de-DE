# Auflistung (Klasse)

Stellt die Definition einer Auflistung dar.

## Eigenschaften

| Eigenschaft | Beschreibung |
| --- | --- |
| [baseType](p-enumeration-basetype.md) | Gibt eine Zeichenfolge zurück, die den Auflistungstyp angibt. |
| [Standard](p-enumeration-default.md) | Gibt eine Zeichenfolge zurück, die den Standardwert der Auflistung angibt. |
| [description](p-enumeration-description.md) | Gibt eine Zeichenfolge zurück, die eine Beschreibung der Auflistung enthält. |
| [hasImage](p-enumeration-hasimage.md) | Gibt einen booleschen Wert zurück, der angibt, ob die Auflistung über ein Bild verfügt. |
| [label](p-enumeration-label.md) | Gibt eine Zeichenfolge zurück, die die Bezeichnung der Auflistung angibt. |
| [name](p-enumeration-name.md) | Gibt eine Zeichenfolge zurück, die den Namen der Auflistung angibt. |
| [Werte](p-enumeration-values.md) | Gibt ein -Objekt zurück, für das jede Eigenschaft ein [EnumerationValue](c-enumerationvalue.md) -Objekt ist, das anhand seines Werts indiziert wird. |
