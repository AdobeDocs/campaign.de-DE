# createElementNS

Erstellt ein neues Element mit dem angegebenen Namen und Namespace.

```text
createElementNS (namespaceURI, qualifiedName)
```

## Parameter

**namespaceURI** Namespace-URI.

**qualifiedName** Qualifizierter Name des zu erstellenden Elements.

## Rückgabewert

[element](c-domelement.md) erstellt.
