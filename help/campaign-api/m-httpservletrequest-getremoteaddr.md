# getRemoteAddr

Gibt die IP-Adresse des Clients oder den letzten Proxy zurück, der eine Anfrage gesendet hat.

```text
getRemoteAddr ()
```

## Parameter

Keine.

## Rückgabewert

Eine Zeichenfolge, die die IP-Adresse des Clients enthält, der die Abfrage gesendet hat.

## Funktionen

**Methode der Klasse:** [HttpServletRequest](c-httpservletrequest.md)

**Verfügbar in:**

* JSSP
* WEBAPP
