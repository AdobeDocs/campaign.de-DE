# ResolvePackageReferences

Löst die im Package enthaltenen Abhängigkeiten

```text
[ XML patchedPackage, Number warningNb ] = ResolvePackageReferences ( XML parameters )
```

## Parameter

**parameters** XML-Element, das das zu importierende Paket enthält.

## Rückgabewert(e)

**patchedPackage** Verarbeitetes Paket.

**warningNb** Anzahl der erzeugten Warnungen.

## Funktionen

**Schema:** [xtk:builder](s-xtk-builder.md)

**static:**

Ja
