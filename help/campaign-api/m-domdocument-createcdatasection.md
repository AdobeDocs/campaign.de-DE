# createCDATASection

Erstellt einen neuen Knoten vom Typ CDATA.

```text
createCDATASection (data)
```

## Parameter

**data** Zeichenfolge, die in den CDATA-Knoten eingefügt werden soll.

## Rückgabewert

[CDATA-Knoten](c-domcharacterdata.md) erstellt.
