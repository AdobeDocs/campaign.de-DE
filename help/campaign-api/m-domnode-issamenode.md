# isSameNode

Prüft, ob die angegebene Referenz denselben Knoten darstellt.

```text
isSameNode ()
```

## Parameter

Keine.

## Rückgabewert

true, wenn beide Verweise denselben Knoten darstellen, andernfalls false.

## Bemerkungen

Diese Methode muss verwendet werden, um zwei Verweise zu vergleichen. Die JavaScript-Operatoren == und === können nicht verwendet werden.
