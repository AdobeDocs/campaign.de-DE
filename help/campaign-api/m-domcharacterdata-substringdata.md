# substringData

Extrahieren Sie einen Teil des Textes.

```text
substringData (offset, count)
```

## Parameter

**offset** Position des ersten Zeichens (0 für das erste Zeichen).

**count** Anzahl der zu extrahierenden Zeichen.

## Rückgabewert

Extrahierter String
