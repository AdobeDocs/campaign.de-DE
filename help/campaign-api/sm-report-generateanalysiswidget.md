# GenerateAnalysisWidget

Erzeugt das Widget zur Anzeige.

```text
XML javascript = GenerateAnalysisWidget ( XML entity, String javascriptId, XML queryResult )
```

## Parameter

**entity** XML-Dokument, das das Widget beschreibt

**javascriptId** Eindeutige ID des Widgets

**queryResult** XML-Dokument, das die Daten enthält

## Rückgabewert(e)

**javascript** Widget-Erstellung JavaScript
