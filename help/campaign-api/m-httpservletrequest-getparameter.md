# getParameter

Gibt den Wert eines Abfrageparameters zurück.

```text
getParameter (name)
```

## Parameter

**name** Parametername.

## Rückgabewert

Der Wert des angeforderten Parameters.

## Funktionen

**Methode der Klasse:** [HttpServletRequest](c-httpservletrequest.md)

**Verfügbar in:**

* JSSP
* WEBAPP
