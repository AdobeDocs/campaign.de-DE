# setIdAttributeNS

Deklariert das angegebene Attribut als Attribut vom Typ ID.

```text
setIdAttributeNS (namespaceURI, localName)
```

## Parameter

**namespaceURI** URI des Attribut-Namespace.

**localName** Attributname.

## Rückgabewert

Keine.
