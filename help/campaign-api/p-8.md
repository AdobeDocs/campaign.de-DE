# Datenschutz: Funktionen umgehen

Adobe Campaign bietet eine Reihe von Funktionen, die Schutz vor den häufigsten Angriffen bieten: SQL-Injections, XSS-Angriffe usw.

Escaping-Funktionen sind unter der Aufsicht von Operatoren zu verwenden und Adobe kann nicht für die schlechte Verwendung oder das Fehlen der Verwendung dieser Funktionen während der Entwicklung verantwortlich gemacht werden.

Die allgemeine Regel lautet wie folgt:

**Alle Parameter müssen maskiert werden. Die zum Maskieren verwendete Funktion hängt vom Zielformat der Daten ab.**

## Vereinfachtes Maskieren

In den JSSPs stellt Adobe Campaign das Tag &quot;&lt;%=&quot; bereit, mit dem Sie eine Variable, die in einer generierten XML- oder HTML-Entität verwendet wird, mit Escape-Zeichen versehen können. Diese Methode ist praktischer und entspricht NL.XML.escape(). Das folgende Beispiel veranschaulicht die Verwendung des -Tags, um einen -Parameter mit Escape-Zeichen zu versehen:

```xml
<li>
<%= strRecipientList %>
</li>
```

## Erweitertes Maskieren:

Adobe Campaign bietet vier Funktionen, mit denen Sie einen Parameter je nach Zielformat mit Escape-Zeichen versehen können. Um auf diese Escape-Funktionen zuzugreifen, benennen Sie die folgenden Dateien:

```javascript
NL.require('/nl/core/shared/xml.js')
NL.require('/nl/core/sql.js')
NL.require('/nl/core/shared/xtk.js')
NL.require('/nl/core/shared/js.js')
```

* NL.XML.escape(data) : Zum Maskieren einer Variablen, die in einer generierten XML- oder HTML-Entität verwendet wird. Diese Funktion entspricht der Syntax &#39;&lt;%=&#39;. Diese Funktion wird im Paket NL.XML definiert.

  ```xml
  <tr>
  <td><%==NL.XML.escape(node.id)%><td>
  <td><%==NL.XML.escape(node.label)%><td>
  </tr>
  ```

* NL.SQL.escape(data) , um einen Parameter mit Escape-Zeichen zu versehen, der in einer SQL-Abfrage verwendet werden kann. Diese Funktion platziert den Ausdruck automatisch zwischen einfachen Anführungszeichen. Diese Funktion wird im Paket NL.SQL definiert.

  ```javascript
            var strSql = "UPDATE NmsRecipient SET sEmail="+NL.SQL.escape(strEmail)+ " WHERE ...";
  ```

* NL.XTK.toXTKString(data) zum Maskieren eines Parameters, der für die Verwendung in einem XTK-Ausdruck vorgesehen ist. Diese Funktion wird im Paket NL.XTK definiert.

  ```javascript
  var query = NLWS.xtkQueryDef.create(
    {queryDef: {schema: "nms:recipient", operation: "select", 
      select: {
        node: [
          {expr: "@firstName"}, 
          {expr: "@lastName"} 
        ]
      }, 
      where: {
        condition: {expr: "@email=" + NL.XTK.toXTKString(request.getParameter("query"))}
      }
    }})
  ```

* NL.JS.escape(data), um eine Variable zu umgehen, die in JavaScript verwendet wird, das auf der Client-Seite ausgeführt wird. Diese Funktion wird im Paket NL.JS definiert.

  ```xml
  <script type="text/javascript">
                var value = “Foo <%== NL.JS.escape(Node.@value) %>”; 
  </script>
  ```

Achtung: Adobe Campaign übernimmt keine Garantie für die Dauerhaftigkeit dieser Funktionen für neuere Versionen.
