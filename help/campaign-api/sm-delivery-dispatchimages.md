# Bilder senden

Veranlasst den Anwendungs-Server, die Bilder an den Mid-Sourcing-Server zu senden

```text
DispatchImages ( String images, Number providerId, String providerName )
```

## Parameter

**images** Liste von Bildern, die auf den Mid-Sourcing-Server hochgeladen werden.

**providerId** Kennung des Versand-Routers.

**providerName** Name des Versand-Routers.

## Rückgabewert(e)

Keine.

## Funktionen

**Schema:** [nms:delivery](s-nms-delivery.md)

**static:**

Ja
