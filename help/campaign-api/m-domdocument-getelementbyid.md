# getElementById

Gibt das Element mit der angegebenen ID zurück.

```text
getElementById (elementId)
```

## Parameter

**elementId** Kennung des durchsuchten Elements. Eine Zeichenfolge mit Unterscheidung zwischen Groß- und Kleinschreibung.

## Rückgabewert

Das Element oder null, wenn das Dokument kein Element mit einer bestimmten ID enthält.
