# verfügen

Gibt die vom -Objekt verwendeten Ressourcen frei.

```text
dispose ()
```

## Parameter

Keine.

## Rückgabewert

Keine.

## Bemerkungen

Diese Methode ist nützlich, um vom -Objekt verwendete Ressourcen freizugeben, ohne darauf zu warten, dass das -Objekt vom Garbage Collector oder vom Ende des Skripts abgeschlossen wird.
