# hasAttributes

Prüft, ob der Knoten mindestens ein Attribut hat.

```text
hasAttributes ()
```

## Parameter

Keine.

## Rückgabewert

„true“, wenn der Knoten ein oder mehrere Attribute hat, andernfalls „false“.
