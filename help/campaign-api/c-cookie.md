# Cookie (Klasse)

Stellt ein Cookie dar, das vom Servlet und vom Webbrowser ausgetauscht wird.

## Eigenschaften

| Eigenschaft | Beschreibung |
| --- | --- |
| [name](p-cookie-name.md) | Cookie-Name. |
| [Kommentar](p-cookie-comment.md) | Kommentar, der die Funktion des Cookies beschreibt, null, wenn nicht definiert. |
| [Domain](p-cookie-domain.md) | Der Domain-Name des Cookies. |
| [maxAge](p-cookie-maxage.md) | Cookie-Lebensdauer in Sekunden. |
| [path](p-cookie-path.md) | Pfad, über den der Webbrowser das Cookie weiterleitet. |
| [sicher](p-cookie-secure.md) | true, wenn das Cookie nur über ein sicheres Protokoll weitergeleitet werden kann. |
| [value](p-cookie-value.md) | Cookie-Wert. |
| [version](p-cookie-version.md) | Protokollversion, mit der das Cookie kompatibel ist. |

## Funktionen

**Verfügbar in:**

* JSSP
* WEBAPP
