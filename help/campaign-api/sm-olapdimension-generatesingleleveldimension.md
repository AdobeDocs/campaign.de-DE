# GenerateSingleLevelDimension

Auf einem Feld basierende Dimension mit nur einer Ebene erzeugen

```text
XML result = GenerateSingleLevelDimension ( XML dimension, XML field )
```

## Parameter

**Dimension** Einzugebende Dimension

**Feld** Feld oder Ausdruck verwendet

## Rückgabewert(e)

**Ergebnis** Eingegebene Dimension

## Funktionen

**Schema:** [xtk:olapDimension](s-xtk-olapdimension.md)

**static:**

Ja
