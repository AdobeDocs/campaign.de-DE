# toString

Gibt den Inhalt des [MemoryBuffer](c-memorybuffer.md) in Form einer Zeichenfolge zurück.

```text
toString ( [codePage ])
```

## Parameter

**codePage** Eine Ganzzahl, die die Seite der verwendeten Zeichen codiert. Standardmäßig ist MemoryBuffer.CODEPAGE\_UTF8.

## Rückgabewert

Der Inhalt eines Stempels in Form einer Zeichenfolge.
