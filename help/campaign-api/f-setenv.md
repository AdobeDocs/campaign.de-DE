# setEnv

>[!WARNING]
>
>Diese Funktion ist für eine On-Premise-Umgebung verfügbar.

>[!NOTE]
>
>Sie können diese Funktion deaktivieren, indem Sie die Option **XtkSecurity\_Disable\_GetSetEnv** an **true** übergeben.

Legen Sie den Wert einer Umgebungsvariablen fest.

```text
setEnv (name, value)
```

## Parameter

**name** Name der Umgebungsvariablen.

**Wert** Neuer Wert für die Umgebungsvariable.

## Rückgabewert

Der neue Wert der Variablen.
