# Muster

## Statische Methoden

Der Zugriff auf die SOAP-Methoden erfolgt durch Aufrufen einer -Methode für das -Objekt, das das Schema darstellt. Die Schemata sind globale „NLWS“-Objekte. Im folgenden Beispiel wird die statische [PostEvent](sm-workflow-postevent.md) des [xtk:workflow](s-xtk-workflow.md)-Schemas aufgerufen.

```javascript
      NLWS.xtkWorkflow.PostEvent("WKF1", "signal", "", {variables: {foo: 'bar'}}, false)
    
```

## Nicht statische Methoden

Um die nicht statischen SOAP-Methoden zu verwenden, müssen Sie zunächst eine Entität mit den Methoden [load](f-load.md) oder [create](f-create.md) für die entsprechenden Schemata wiederherstellen. Im folgenden Beispiel wird die Methode [ExecuteQuery](sm-querydef-executequery.md) des [xtk:queryDef](s-xtk-querydef.md)-Schemas aufgerufen.

```javascript
var query = NLWS.xtkQueryDef.create(
  {queryDef: {schema: "xtk:workflow", operation: "select", 
    select: {
      node: {expr: "@internalName"}
    }, 
    where: {
      condition: {expr: "[folder/@name]='wfExamples'"}
    }, 
    orderBy: {
      node: {expr: "@internalName", sortDesc: "false"}
    }
  }})

var res = query.ExecuteQuery()

for each (var w in res.getElements("workflow"))
  logInfo(w.$internalName)
    
```

## Einschränkungen

Bestimmte nicht statische Aufrufe können nicht verwendet werden, da dem geladenen Objekt (\*\*) die Daten fehlen. Dies ist beispielsweise bei bestimmten Aufrufen auf „nms[&#x200B; der Fall:delivery](s-nms-delivery.md).
