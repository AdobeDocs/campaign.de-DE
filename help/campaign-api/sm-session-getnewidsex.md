# GetNewIdsEx

Erstellt unter Angabe der anzuwendenden Sequenz eine Liste der eindeutigen Kennungen der Datenbank

```text
String idList = GetNewIdsEx ( Number count, String sequence )
```

## Parameter

**count** Anzahl der Kennungen, die diese Methode zurückgeben soll

**Sequenz** Name der zu inkrementierenden Sequenz

## Rückgabewert(e)

**idList** Durch Kommas getrennte Liste von Bezeichnern

## Funktionen

**Schema:** [xtk:session](s-xtk-session.md)

**static:**

Ja
