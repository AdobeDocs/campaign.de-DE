# isDefaultOnDuplicate

Gibt einen booleschen Wert zurück. Wenn der hinzugefügte Wert variiert, wird während der Datensatzdeduplizierung der Standardwert (definiert in defaultValue) während der Aufzeichnung automatisch erneut angewendet.

```text
isDefaultOnDuplicate
```

## Funktionen

**Eigenschaft der Klasse:** [SchemaNode](c-schemanode.md)

**Schreibgeschützt:**

Ja
