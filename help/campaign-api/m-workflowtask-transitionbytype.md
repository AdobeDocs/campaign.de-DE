# transitionByType

Gibt die dem angegebenen Typ entsprechende Transition zurück.

```text
transitionByType (type)
```

## Parameter

**type** Typ der Transition.

## Rückgabewert

Die erste Transition, an die der Typ als Parameter übergeben wird, andernfalls null, wenn die Aktivität keine Transition dieses Typs hat.

**Methode der Klasse:** [WorkflowTask](c-workflowtask.md)
