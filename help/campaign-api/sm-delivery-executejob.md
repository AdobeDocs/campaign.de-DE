# ExecuteJob

Führt einen asynchronen Vorgang im Bezug auf einen Versand aus.

```text
ExecuteJob ( String methodName, Number id )
```

## Parameter

**methodName** Name der Methode, die für die Entität aufgerufen wird

**id** Versandkennung

## Rückgabewert(e)

Keine.
