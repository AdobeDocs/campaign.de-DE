# FTP (Klasse)

Mit einem FTP-Objekt können Sie eine Reihe von Vorgängen unter Verwendung des FTP-Protokolls durchführen.

## Methoden

| Methode | Beschreibung |
| --- | --- |
| [FTP](m-ftp-ftp.md) | Erstellt ein neues Objekt zum Ausführen von FTP-Befehlen. |
| [dispose](m-ftp-dispose.md) | Gibt die vom -Objekt verwendeten Ressourcen frei. |
| [list](m-ftp-list.md) | Gibt die Liste der Dateien auf dem Server in einem angegebenen Verzeichnis zurück. |
| [Herunterladen](m-ftp-download.md) | Lädt eine Datei vom Server in eine lokale Datei oder in den Speicher herunter. |
| [Upload](m-ftp-upload.md) | Herunterladen einer Datei von einer lokalen Datei auf einen FTP-Server. |
| [setFile](m-ftp-setfile.md) | Definiert den Übertragungsmodus und die empfangende Datei. |
