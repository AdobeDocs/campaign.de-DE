# fileSize

Gibt die Größe einer Datei in Byte zurück.

```text
fileSize (filename)
```

## Parameter

**filename** Der vollständige Dateiname.

## Rückgabewert

Gibt die Größe der Datei zurück oder -1, wenn ein Fehler aufgetreten ist (z. B. wenn die Datei nicht gefunden wurde).
