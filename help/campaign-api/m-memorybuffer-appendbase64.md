# appendBase64

Fügt Daten aus einer in Base 64 kodierten Zeichenfolge an das Ende des Puffers an.

```text
appendBase64 (string)
```

## Parameter

**string** Eine Zeichenfolge, die die in Base 64 kodierten Binärdaten darstellt, die dem Puffer hinzugefügt werden sollen.

## Rückgabewert

Keine.
