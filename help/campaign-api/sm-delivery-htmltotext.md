# htmlToText

Konvertiert HTML-Inhalt in einfachen Text

```text
String textContent = HtmlToText ( String htmlContent )
```

## Parameter

**htmlContent** zu konvertierender HTML-Inhalt

## Rückgabewert(e)

**textContent** Gibt den konvertierten Text zurück.
