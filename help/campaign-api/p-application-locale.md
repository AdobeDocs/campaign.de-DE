# Gebietsschema

Gibt einen String zurück, der der lokalen Instanz entspricht.

```text
locale
```

## Bemerkungen

Der lokale ist ein Code, der regionale Einstellungen definiert. Er besteht aus einem Sprach-Code, gefolgt von einem Länder-Code, getrennt durch &quot;-&quot;. Beispiele für Werte:

* en-US - Englisch, Vereinigte Staaten
* en-GB - Englisch, Großbritannien
* fr-FR - Französisch, Frankreich
* de-DE - Deutsch, Deutschland
* es-ES - Spanisch, Spanien
