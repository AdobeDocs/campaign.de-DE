# updateFacebookProfile

```text
Number result = updateFacebookProfile ( String accessToken )
```

## Parameter

**accessToken**

## Rückgabewert(e)

**result** Gibt die ID der Adobe Campaign-Entität zurück, die dem Facebook-Zugriffstoken entspricht. Wenn der Code nicht gleich 0 ist, war der Aufruf erfolgreich.
