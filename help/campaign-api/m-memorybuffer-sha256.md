# SHA256

Berechnet die 256-Bit-Signatur des MemoryBuffer-Inhalts von SHA-2.

```text
sha256 ()
```

## Parameter

Keine.

## Rückgabewert

Eine Zeichenfolge, die die hexadezimale Darstellung der 256-Bit-Signatur von SHA-2 darstellt.
