# reverseLink

Wenn das Element eine Relation ist, gibt ein [SchemaNode](c-schemanode.md)-Objekt zurück, das eine Umkehrrelation (über das Zielschema) darstellt. Ist dies nicht der Fall, wird die Eigenschaft nicht definiert.

```text
reverseLink
```

## Funktionen

**Eigenschaft der Klasse:** [SchemaNode](c-schemanode.md)

**Schreibgeschützt:**

Ja

* Versandeigenschaften
* Typologieregel
