Ändert den imageConfig-Knoten, damit die bereits auf dem Server befindlichen Bilder berücksichtigt werden.

```text
XML imageConfig = UpdateImageConfig ( XML imageConfig )
```

**imageConfig** Konfiguration der Bildverarbeitung
