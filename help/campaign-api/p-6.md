# Verwenden von XML

Viele JavaScript-APIs nehmen XML-Typobjekte als Parameter oder geben sie zurück. Frühere Versionen von Adobe Campaign verwendeten hierfür die JavaScript E4X-Erweiterung, mit der XML-Elemente direkt in der Sprache bearbeitet werden konnten. Diese Technologie wird jedoch langsam aufgegeben.

Um diese Technologie zu ersetzen, wurden neue Objekte hinzugefügt, um XML-Dokumente zu bearbeiten. Sie setzen eine Untergruppe der DOM-Schnittstelle (Document Object Model) mit einigen Erweiterungen fort. Ein Notation -Objekt ist auch verfügbar, um XML-Dokumente einfach zu erstellen, es ist eine vereinfachte Version der JSON BadgetFish -Konvention.

## DOM-Schnittstelle

Ein [DOMDocument](c-domdocument.md)-Objekt ist ein XML-Dokument. Es kann aus einer Zeichenfolge, einem JSON-Objekt oder direkt aus einer Datei erstellt werden. Im Folgenden finden Sie ein Beispiel für das Erstellen eines DOM-Dokuments:

```javascript
var doc  = new DOMDocument("recipient")
var root = doc.root
root.setAttribute("id", 12345)
var firstName = doc.createElement("firstName")
firstName.textContent = "John"
root.appendChild(firstName)

logInfo(doc.toXMLString(true))
```

Diese Schnittstelle war Teil der W3C-Spezifikation mit verschiedenen bemerkenswerten Unterschieden:

* Die getElements\*-Funktionen sowie die childNodes-Eigenschaft und die attribute-Eigenschaft geben eine JavaScript-Tabelle anstelle eines NodeList-Objekts zurück. Dies ermöglicht die Verwendung der eigenen Tabellenfunktionen: forEach, Map, …
* Bestimmte Eigenschaften geben eine leere Zeichenfolge anstelle von null zurück, wenn der Wert nicht angegeben wurde.

Darüber hinaus wurden bestimmte Dienstprogrammfunktionen und einige nicht standardmäßige Erweiterungen hinzugefügt. Um beispielsweise ein Attribut zu lesen oder zu ändern, müssen Sie nur schreiben:

```javascript
aRecipient.$firstName
aRecipient.$firstName = "John"
```

anstelle von:

```javascript
aRecipient.getAttribute("firstName")
aRecipient.setAttribute("firstName", "John")
```

Wenn ein Attribut mit der $name-Eigenschaft zugewiesen wird, kann dies eine Zeichenfolge, einen booleschen Wert, ein Datum oder eine Zahl erfordern. Der Wert wird automatisch in eine Zeichenfolge konvertiert:

```javascript
aRecipient.$firstName = "John"
aRecipient.$lastModified = new Date()
aRecipient.$age = 35
aRecipient.$blocklist = false
```

## JXON

JXON ist eine Notierungskonvention für JavaScript-Objekte zum einfachen Erstellen von XML-Dokumenten. Mit dieser Notation können nicht alle möglichen XML-Dokumente erstellt werden. Beispielsweise ist es nicht zulässig, ein Element mit demselben Namen wie ein Attribut anzugeben, und die Namespaces werden nicht verwaltet. Es ist für Adobe Campaign-Dokumente geeignet. Für komplexere Anforderungen können Sie immer herkömmliche DOM-Funktionen verwenden (Analysieren oder Element für Element erstellen). Das XML-Objekt wird durch ein JavaScript-Objekt dargestellt, dessen Eigenschaften mit den Elementen und Attributen übereinstimmen. Der Werttyp bestimmt, ob er mit einem Element oder einem Attribut zu tun hat.

* String Ein Attribut, dessen Wert die Zeichenfolge ist
* Boolesches Attribut, dessen Wert entweder „true“ oder „false“ ist
* Zahl Ein Attribut, dessen Wert die Dezimalzahldarstellung ist
* Datum Ein Attribut, dessen Wert die ISO-8601-Darstellung von Datum und Uhrzeit ist
* Objekt ein Element
* Array : Eine Liste der Elemente

Eine spezielle Eigenschaft unter dem Namen $ wird für den Textinhalt eines Elements verwendet. Beispiele:

> **JXON:**
>
> ```javascript
> { alice: { $: "bob" } }
> ```
>
> **XML:**
>
> ```xml
> <alice>bob</alice>
> ```
>
> **JXON:**
>
> ```javascript
> { alice: { 
>     bob: { $: "charlie" }, 
>     david: { $: "edgar" }
> }}
> ```
>
> **XML:**
>
> ```xml
> <alice>
>     <bob>charlie</bob>
>     <david>edgar</david>
> </alice>
> ```
>
> **JXON:**
>
> ```javascript
> { alice: { 
>     bob: [
>         { $: "charlie" }, 
>         { $: "david" } ]
> }}
> ```
>
> **XML:**
>
> ```xml
> <alice>
>     <bob>charlie</bob>
>     <bob>david</bob>
> </alice>
> ```
>
> **JXON:**
>
> ```javascript
> { alice: { 
>     charlie: "david",
>     $: "bob"
> }}
> ```
>
> **XML:**
>
> ```xml
>                             <alice charlie="david">bob</alice>
> ```
>
> **JXON:**
>
> ```javascript
> { recipient: {
>     firstName: "John",
>     id: 1234,
>     "creation-date": getCurrentDate(),
>     blocklist: false
> }}
> ```
>
> **XML:**
>
> ```xml
> <recipient
>     firstName="John"
>     id="1234"
>     creation-date="2013-04-19 10:58:22Z"
>     blocklist="false"/>
> ```

Wenn Eigenschaften Sonderzeichen enthalten, die ungültige JavaScript-Kennungen sind, müssen diese in Anführungszeichen gesetzt werden.

```javascript
{ recipient: { "recipient-id" : 1234 }}
      
```

JSON-Objekte können überall dort in Argumenten verwendet werden, wo eine Funktion ein Dokument oder ein XML-Element antizipiert. Beispiel:

```javascript
var doc = DOMDocument.fromJXON({queryDef: 
    {schema: "xtk:workflow", operation: "select",
      select: { node: {expr: "@internalName"} } 
    }
  })
var query = NLWS.xtkQueryDef.create(doc)
```

entspricht:

```javascript
var query = NLWS.xtkQueryDef.create({queryDef: 
    {schema: "xtk:workflow", operation: "select",
      select: { node: {expr: "@internalName"} } 
    }
  })
```

Es ist wichtig zu beachten, dass die Bearbeitung von XML-Dokumenten durch DOM-Objekte erfolgt. Die JSON-Objekte sind Dienstprogramme, die nur für die Initialisierung verwendet werden. Es ist nützlicher, ein XML-Dokument aus einer literalen JavaScript-Struktur zu erstellen, insbesondere wenn das Dokument variable Teile enthält.
