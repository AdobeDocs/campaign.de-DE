# Alias-Verwaltung

Aktualisierung der Datenbank mit Hilfe aller dem Alias unterliegenden Auflistungen

```text
AliasCleansing ( XML where, Date fromDate, Boolean refreshHit, Boolean resetHit )
```

## Parameter

**where** Auflistungsfilter.

**fromDate** Startdatum für Umfrageantworten.

**refreshHit** Treffer aktualisieren.

**resetHit** Treffer-Aktualisierung von Anfang an.

## Rückgabewert(e)

Keine.

**static:**

Ja
