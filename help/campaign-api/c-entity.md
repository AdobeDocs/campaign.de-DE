# Entität (Klasse)

Stellt eine Entität der Datenbank für ein bestimmtes Schema dar.

Ein solches Objekt kann nicht direkt instanziiert werden. Sie müssen die Methoden create(), get() oder load() verwenden.

## Methoden

| Methode | Beschreibung |
| --- | --- |
| [Speichern](m-entity-save.md) | Speichert eine Entität in der Datenbank |
