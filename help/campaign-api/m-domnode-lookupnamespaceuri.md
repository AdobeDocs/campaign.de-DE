# lookupNamespaceURI

Durchsucht den URI des Namespace, der mit dem angegebenen Präfix verknüpft ist.

```text
lookupNamespaceURI (prefix)
```

## Parameter

**prefix** Präfix.

## Rückgabewert

URI des Namespace oder eine leere Zeichenfolge, wenn sie nicht gefunden wurde.
