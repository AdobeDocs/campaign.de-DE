# postEvent

Aktiviert eine Transition.

```text
postEvent (transition)
```

## Parameter

**transition** Die zu aktivierende Transition.

## Rückgabewert

Keine.

## Bemerkungen

Die Zielaktivität der Transition wird aktiviert und erhält die Variablen der Aufgabe.
