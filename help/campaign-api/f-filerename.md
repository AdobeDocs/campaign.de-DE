# fileRename

Ändert den Namen einer Datei.

Wenn die Zeichenkodierung nicht angegeben ist, wird der Server-Standard verwendet.

```text
fileRename (oldname, newname)
```

## Parameter

**oldname** Der vollständige Name der umzubenennenden Datei.

**newname** Der neue Name der Datei.

## Rückgabewert

Keine.
