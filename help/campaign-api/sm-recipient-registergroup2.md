# RegisterGroup2

Fügt die ausgewählten Empfänger zu einer Liste hinzu

```text
RegisterGroup2 ( XML groupList, XML recipientList, XML clearGroup )
```

## Parameter

**groupList** Listen

**recipientList** Empfängerliste

**clearGroup** Liste neu erstellen

## Rückgabewert(e)

Keine.

Ja
