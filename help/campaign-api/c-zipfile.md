# Zip-Datei (Klasse)

Manipuliert ZIP-Dateien.

## Methoden

| Methode | Beschreibung |
| --- | --- |
| [ZipFile](m-zipfile-zipfile.md) | Erstellt ein neues ZIP-Objekt, das mit einer Datei verknüpft ist. |
| [dispose](m-zipfile-dispose.md) | Gibt die vom -Objekt verwendeten Ressourcen frei. |
| [Öffnen](m-zipfile-open.md) | Lädt ein vorhandenes Archiv. |
| [getEntry](m-zipfile-getentry.md) | Extrahiert eine Datei aus dem Archiv. |
| [setEntry](m-zipfile-setentry.md) | Fügt eine Datei im Archiv hinzu oder aktualisiert sie. |
| [Speichern](m-zipfile-save.md) | Speichert das Archiv. |

## Eigenschaften

| Eigenschaft | Beschreibung |
| --- | --- |
| [fileCount](p-zipfile-filecount.md) | Gibt die Anzahl der Dateien im Archiv aus |
