# CreateFromModel

Erstellung eines Versands von einer Vorlage ausgehend (durch den internen Namen bezeichnet)

```text
XML delivery = CreateFromModel ( String scenarioName, XML content )
```

## Parameter

**scenarioName** Interner Name der Versandvorlage

**content** XML-Inhalt, der der Vorlage hinzugefügt werden soll

## Rückgabewert(e)

**delivery** Gibt das erstellte Versanddokument zurück.

## Funktionen

**Schema:** [nms:delivery](s-nms-delivery.md)

**static:**

Ja
