# AutoDetect

Startet eine Auto-Discovery und gibt die ersten Zeilen der Datei aus

```text
XML result = AutoDetect ( String fileName, Number codepage )
```

## Parameter

**fileName** Dateiname

**codepage** Zeichenkodierung

## Rückgabewert(e)

**result** Gibt die ersten Zeilen der Datei zurück.

## Funktionen

**Schema:** [xtk:dataTransfer](s-xtk-datatransfer.md)

**static:**

Ja
