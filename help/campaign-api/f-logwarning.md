# logWarning

Fügt dem Protokoll der Workflow-Instanz eine Warnmeldung hinzu.

```text
logWarning (message)
```

## Parameter

**message** Die Nachricht, die dem Protokoll hinzugefügt werden soll.

## Rückgabewert

Keine.
