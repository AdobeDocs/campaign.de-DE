# UpdateRealCostFromExpenseLine

Aktualisiert den tatsächlichen Betrag des Versands oder der Aufgabe ausgehend von einer Ausgabenzeile

```text
UpdateRealCostFromExpenseLine ( Number id, String schema, XML budgetParameters )
```

## Parameter

**id** Versand-/Aufgabenkennung

**schema** Entitätsschema (Versand/Aufgabe)

**budgetParameters** Budgetelement für die Entität

## Rückgabewert(e)

Keine.

## Funktionen

**Schema:** [nms:budget](s-nms-budget.md)

**static:**

Ja
