# DumpInstanceStateEx

Gibt den Status des Serverprozesses aus

```text
XML monitoring = DumpInstanceStateEx ( String mask, Boolean includeDead, Boolean noDatabaseCheck, Number criticalLevel )
```

## Parameter

**Maske** Maske für zu berücksichtigende Instanzen

**includeDead** Liste der inaktiven Prozesse hinzufügen

**noDatabaseCheck**: Warnhinweise von Datenbankobjekten werden nicht geprüft

**criticalLevel** Filtert den Schweregrad der zurückgegebenen Warnhinweise

## Rückgabewert(e)

**Überwachung**

## Funktionen

**Schema:** [nl:monitoring](s-nl-monitoring.md)

**static:**

Ja
