# resetServiceMobileAppsCustomHook

Löscht die zusätzlichen Webdienstparameter aller mobileApps eines Dienstes

```text
XML serviceOut = resetServiceMobileAppsCustomHook ( XML serviceContent )
```

## Parameter

**serviceContent** Inhalt des aktuellen Dienstknotens

## Rückgabewert(e)

**serviceOut** Inhalt des Dienstknotens nach der Verarbeitung

## Funktionen

**Schema:** [nms:mobileApp](s-nms-mobileapp.md)

**static:**

Ja
