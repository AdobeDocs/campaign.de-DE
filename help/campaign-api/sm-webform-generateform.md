# Formular generieren

Erzeugt das Formular im E-Mail- oder Webmodus

```text
String result = GenerateForm ( String formName, Boolean mailMode )
```

## Parameter

**formName** Formularname

**mailMode** Formular vom Typ „Mail“ erzeugen

## Rückgabewert(e)

**result** Ergebnis der Anwendung der XSL auf das Formular

## Funktionen

**Schema:** [nms:webForm](s-nms-webform.md)

**static:**

Ja
