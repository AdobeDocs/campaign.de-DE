# getUUID

Erstellung einer eindeutigen Kennung (Universally Unique ID).

```text
getUUID ()
```

## Parameter

Keine.

## Rückgabewert

Eine Zeichenfolge, die die eindeutige ID „550E8400-E29B-41D4-A716-446655440000“ enthält.
