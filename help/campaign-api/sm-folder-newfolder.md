# Neuer Ordner

Erstellen von Ordnern

```text
XML result = NewFolder ( String parentKey, String schema, String entity, String model, String label, String img )
```

## Parameter

**parentKey** Übergeordneter Schlüssel

**schema** Schema

**entity** Entity

**model**-Vorlage

**label** Vorlagentitel

**img** Bildschlüssel

## Rückgabewert(e)

**result** Ergebnisdokument
