# Alle auswählen

Fügt alle Felder in den &#39;SELECT&#39;-Bereich ein

```text
queryDef.SelectAll ( Boolean duplicate )
```

## Parameter

**duplicate** Gibt an, ob dupliziert wird. In diesem Fall werden alle OwnCopy-Elemente hinzugefügt.

## Rückgabewert(e)

Keine.
