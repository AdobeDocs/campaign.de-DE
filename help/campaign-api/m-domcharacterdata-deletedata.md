# deleteData

Löscht einen Teil des Textes.

```text
deleteData (offset, count)
```

## Parameter

**offset** Position des ersten zu löschenden Zeichens (0 für das erste Zeichen).

**count** Anzahl der zu löschenden Zeichen.

## Rückgabewert

Keine.
