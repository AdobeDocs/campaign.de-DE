# SHA512

Berechnet die SHA-2-512-Bit-Signatur des MemoryBuffer-Inhalts.

```text
sha512 ()
```

## Parameter

Keine.

## Rückgabewert

Eine Zeichenfolge, die die hexadezimale Darstellung der SHA-2-512-Bit-Signatur ist.
