# ExecuteTransientQuery

Führt eine Abfrage aus und speichert das Ergebnis in einer Arbeitstabelle

```text
ExecuteTransientQuery ( String name, String label, String sqltable, XML query )
```

## Parameter

**name** Schemaname

**label** Schemakennzeichnung

**sqltable** SQL-Name der Tabelle

**query** Abfragedefinition

## Rückgabewert(e)

Keine.

## Funktionen

**Schema:** [xtk:report](s-xtk-report.md)

**static:**

Ja
