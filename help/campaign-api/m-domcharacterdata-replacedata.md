# replaceData

Ersetzt einen Teil des Textes.

```text
replaceData (offset, count, arg)
```

## Parameter

**offset** Position des ersten zu löschenden Zeichens (0 für das erste Zeichen).

**count** Anzahl der zu löschenden Zeichen.

**arg** String der einzufügenden Zeichen.

## Rückgabewert

Keine.
