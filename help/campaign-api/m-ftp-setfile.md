# setFile

> Warnung:
>
> Der Zugriff über Datei-APIs ist auf die **var**, **sftp** und temporären Ordner von Adobe Campaign beschränkt.

Definiert den Übertragungsmodus und die empfangende Datei.

```text
setFile (filename)
```

## Parameter

**filename** Name der lokalen Datei.

## Rückgabewert

Keine.
