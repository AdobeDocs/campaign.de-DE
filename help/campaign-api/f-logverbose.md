# logVerbose

Fügt dem Protokoll der Workflow-Instanz eine Informationsmeldung hinzu. Diese Nachricht ist nur im Verbose-Modus sichtbar.

```text
logVerbose (message)
```

## Parameter

**message** Die Nachricht, die dem Protokoll hinzugefügt werden soll.

## Rückgabewert

Keine.
