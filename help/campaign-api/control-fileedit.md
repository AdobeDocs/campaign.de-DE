# FileEdit

Mit diesem Steuerelement können Sie einen Dateinamen eingeben.

![FileEdit-Steuerelement](assets/fileedit.56228d2a.png)

## Eigenschaften

**backColor - Zeichenfolge** Hintergrundfarbe (btnshasow, weiß).

**border - string** Ändert den Rahmenstil während des Steuerelements (solid, double, inset, outset, none).

**dlgType - Zeichenfolge** Typ des Dateiauswahlfensters (save, opendir, savedir).

**filter - Zeichenfolge** Liste der Filter

**font-size - integer** Ändert die Schriftgröße.

**label - Zeichenfolge** Zugeordnete Bezeichnung.

**lastPath - Zeichenfolge** Pfad des Dateiauswahlfensters.

**loadContent - Boolescher Wert** Lädt den Inhalt einer Datei.

**nolabel - Boolesch** Blendet die zugehörige Beschriftung aus.

**readOnly - boolean** Erzwingt, dass das Steuerelement schreibgeschützt ist.

**erforderlich - boolesch** Das Feld ist obligatorisch.

**title - Zeichenfolge** Titel des Auswahlfensters

**xpathCopyName - xpath** Pfad zum Speichern des Dateinamens (mit der Erweiterung).

**xpathType - xpath** Dateityp (Text oder XML)
