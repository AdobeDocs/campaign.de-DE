# getOption

Gibt den Wert einer Option in der Optionstabelle zurück.

```text
getOption (name [, useCache ])
```

## Parameter

**name** Name der Option.

**useCache** Verwenden Sie den Cache für den Optionswert (er wird standardmäßig nicht verwendet).

## Rückgabewert

Der Wert der Option, wenn die Option existiert, andernfalls nicht definiert. Der Typ des Werts hängt vom Typ der Option ab.
