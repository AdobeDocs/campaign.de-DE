# deployTriggerMessages

Ausgewählte Transaktionsnachrichten in den Ausführungsinstanzen veröffentlichen

```text
DeployTriggerMessages ( XML deliveries, Boolean localPublish )
```

## Parameter

**Sendungen** Filterbedingungen zum Definieren der bereitzustellenden Transaktionsnachrichten

**localPublish** Nur auf der Kontrollinstanz veröffentlichen?

## Rückgabewert(e)

Keine.

## Funktionen

**Schema:** [nms:delivery](s-nms-delivery.md)

**static:**

Ja
