# buildMirror

Erstellt die HTML-Mirrorseite

```text
[ String content, Number responseCode ] = BuildMirror ( String crypted )
```

## Parameter

**verschlüsselt** Reversible Verschlüsselung für Kennungen von Nachrichten und Versandkontingenten

## Rückgabewert(e)

**content** Inhalt der Mirrorseite

**responseCode** HTTP-Antwort im Fehlerfall

**Schema:** [nms:delivery](s-nms-delivery.md)

Ja
