# Abmelden

Meldet einen Benutzer von einem Diskussionsforum ab

```text
Unsubscribe ( Number operatorId, String schema, Number entityId )
```

## Parameter

**operatorId** Benutzer-ID

**schema** Schema der dem Forum zugeordneten Entität

**entityId** ID der mit dem Forum verknüpften Entität

## Rückgabewert(e)

Keine.

## Funktionen

**Schema:** [nms:newsgroup](s-nms-newsgroup.md)

**static:**

Ja
