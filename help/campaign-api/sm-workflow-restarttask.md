# Aufgabe neu starten

Erzwingt den Neustart einer oder mehrerer abgeschlossener Aufgaben.

```text
RestartTask ( String workflowId, String activityName )
```

## Parameter

**workflowId** Kennung oder interner Name des Workflows.

**activityName** Name der neu zu startenden Aktivität(en)

## Rückgabewert(e)

Keine.

## Funktionen

**Schema:** [xtk:workflow](s-xtk-workflow.md)

**static:**

Ja
