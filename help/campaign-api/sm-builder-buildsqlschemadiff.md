# BuildSqlSchemaDiff

Erzeugt ein Dokument, das die Unterschiede zwischen der physischen Datenbank und ihrer logischen Beschreibung aufzeigt.

```text
XML sqlSchemaDiff = BuildSqlSchemaDiff ( XML sqlDiffParam, XML package )
```

## Parameter

**sqlDiffParam**-Erweiterungsparameter

**package** Ursprüngliches Paket

## Rückgabewert(e)

**sqlSchemaDiff** Erzeugtes SqlSchemaDiff

## Funktionen

**Schema:** [xtk:builder](s-xtk-builder.md)

**static:**

Ja
