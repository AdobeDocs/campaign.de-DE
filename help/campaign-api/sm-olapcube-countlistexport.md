# CountListExport

```text
Number result = CountListExport ( Number cubeId, XML cube, XML conditions, String path )
```

## Parameter

**cubeId** Cube-Kennung

**cube** Serialisierter XML-Code, der den Cube beschreibt

**Bedingungen** Auswahlliste

**path** Pfad zu den zu exportierenden Elementen

## Rückgabewert(e)

**result** Anzahl der zu exportierenden Elemente

## Funktionen

**Schema:** [xtk:olapCube](s-xtk-olapcube.md)

**static:**

Ja
