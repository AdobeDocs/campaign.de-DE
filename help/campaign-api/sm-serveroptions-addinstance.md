# Instanz hinzufügen

> Warnung: Diese Funktion ist für eine On-Premise-Umgebung verfügbar.

Deklariert eine neue Instanz auf dem Server

```text
AddInstance ( String instanceName, String hosts, String lang )
```

## Parameter

**instanceName** Name der zu erstellenden Instanz

**hosts** DNS-Masken, die mit der Instanz verknüpft sind

**lang** Instanzsprache

## Rückgabewert(e)

Keine.

## Funktionen

**Schema:** [xtk:serverOptions](s-xtk-serveroptions.md)

**static:**

Ja
