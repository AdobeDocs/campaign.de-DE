# Versandbudget auswerten

Wertet das Budget eines Versands aus.

```text
Number result = EvaluateDeliveryBudget ( Number deliveryId, Number nbMessage )
```

## Parameter

**deliveryId** Versand-ID

**nbMessage** Anzahl der zu sendenden Nachrichten.

## Rückgabewert(e)

**Ergebnis** Evaluiertes Budget.

## Funktionen

**Schema:** [nms:localOrder](s-nms-localorder.md)

**static:**

Ja
