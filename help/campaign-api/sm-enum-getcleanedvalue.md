# GetCleanedValue

Ausgabe einer bereinigten Version eines Werts

```text
String value = GetCleanedValue ( Number enumId, String alias )
```

## Parameter

**enumId** Auflistungs-ID

**alias** Wert, der ersetzt werden soll

## Rückgabewert(e)

**value** Bereinigter Wert (wenn nicht gefunden, wird der Alias zurückgegeben)

## Funktionen

**Schema:** [xtk:enum](s-xtk-enum.md)

**static:**

Ja
