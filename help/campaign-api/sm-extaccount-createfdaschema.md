# Erstellen eines FDAS-Schemas

Erstellt das Arbeitsschema in der Datenbank

```text
CreateFDASchema ( String server, String account, String password, String port, String options, String schema )
```

## Parameter

**server** Server-Adresse

**Konto** Name (oder Login) des Kontos

**Kennwort** Passwort des Kontos

**port** Server-Port

**options** Verbindungsoptionen

**schema** Schemaname

## Rückgabewert(e)

Keine.

## Funktionen

**Schema:** [nms:extAccount](s-nms-extaccount.md)

**static:**

Ja
