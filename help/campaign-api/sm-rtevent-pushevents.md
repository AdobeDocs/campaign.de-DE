# Push-Ereignisse

Fügt eine Ereignissammlung ein.

```text
XML ids = PushEvents ( XML eventCollection )
```

## Parameter

**eventCollection** Ereignisauflistung.

## Rückgabewert(e)

**ids** Sammlung, die die Kombination der beim Einfügen verwendeten externen und internen Kennungen enthält.

## Funktionen

**Schema:** [nms:rtEvent](s-nms-rtevent.md)

**static:**

Ja
