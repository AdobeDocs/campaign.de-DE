# getFirstElement

Gibt das erste untergeordnete Element durch Überprüfung der angegebenen Kriterien zurück.

```text
getFirstElement (tagName [, attrName ] [, attrValue ])
```

## Parameter

**tagName** Name des durchsuchten Elements.

**attrName** Name eines Attributs, das einen bestimmten Wert überprüfen muss.

**attrValue** Attributwert.

## Rückgabewert

Erstes Element, das die angegebenen Kriterien oder null überprüft.
