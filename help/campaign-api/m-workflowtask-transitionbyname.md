# transitionByName

Gibt die dem angegebenen Namen entsprechenden Transitionen aus.

```text
transitionByName (name)
```

## Parameter

**name** Name der Transition.

## Rückgabewert

Die Transition mit dem Namen , der als Parameter übergeben wird, andernfalls null, wenn die Aktivität keine Transition mit diesem Namen hat.

**Methode der Klasse:** [WorkflowTask](c-workflowtask.md)
