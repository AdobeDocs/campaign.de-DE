# FillStepsWithFilter

Automatische Skalierung, um homogene Klassen zu gewährleisten.

```text
XML samplingSteps = FillStepsWithFilter ( String schema, String expr, Number classCount, XML filter )
```

## Parameter

**schema** Stammschema der Analyse

**expr** Source-Ausdruck

**classCount** Anzahl der zu erzeugenden Klassen

**filter** Nach dem Schema filtern

## Rückgabewert(e)

**samplingSteps** Liste der Schritte

## Funktionen

**Schema:** [xtk:abstractForm](s-xtk-abstractform.md)

**static:**

Ja
