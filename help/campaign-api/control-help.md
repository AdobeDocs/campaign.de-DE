# Hilfe

Zeigt Text und Bild an.

![Hilfe-Steuerung](assets/help.67cf3e33.png)

## Eigenschaften

**img - Zeichenfolge** Zugehöriges Bild.

**label - Zeichenfolge** Anzuzeigender Text.

## Bemerkungen

Beispiel:

```xml
      <static type="help" label="Please enter your name here."/>

<static type="help">Please enter your name here.</static>
```
