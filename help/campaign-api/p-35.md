# Ausdruck

Enthält das Ergebnis eines JavaScript-Ausdrucks auf der Seite.

## Syntax

&lt;%= JavaScript-Ausdruck %>

## Beispiel

```javascript
      First Name: <b><%= recipient.firstName %></b>
```
