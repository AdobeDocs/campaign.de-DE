# addHeader

Fügt der Antwort einen zusätzlichen HTTP-Header hinzu.

```text
addHeader (nom, valeur)
```

## Parameter

**nom** Name der hinzuzufügenden Kopfzeile.

**value** Wert der hinzugefügten Kopfzeile.

## Rückgabewert

Keine.

## Funktionen

**Methode der Klasse:** [HttpServletResponse](c-httpservletresponse.md)

**Verfügbar in:**

* JSSP
* WEBAPP
