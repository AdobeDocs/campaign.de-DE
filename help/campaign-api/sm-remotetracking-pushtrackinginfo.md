# PushTrackingInfo

Ermöglicht den Upload von Versandinformationen auf den Remote-Trackingserver

```text
PushTrackingInfo ( String instance, String dbId, String jobId, XML document )
```

## Parameter

**instance** Instanzname

**dbId** Datenbankkennung des Kunden, der einen Versand durchführt

**jobId** Versand-ID

**Dokument** Dokument, das die Tracking-Informationen für diesen Versand enthält

## Rückgabewert(e)

Keine.

## Funktionen

**Schema:** [nms:remoteTracking](s-nms-remotetracking.md)

**static:**

Ja
