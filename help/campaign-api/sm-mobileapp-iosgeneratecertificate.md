# iOSGenerateCertificate

Kodiert das bereitgestellte iOS-Zertifikat in base64

```text
String return = iOSGenerateCertificate ( String fileName, String uuid )
```

## Parameter

**fileName** Dateiname

**uuid** Anwendungs-UUID

## Rückgabewert(e)

**return** Die base64-Version des Zertifikats
