# isDefaultNamespace

Prüft, ob der angegebene Namespace der Standard ist.

```text
isDefaultNamespace (namespaceURI)
```

## Parameter

**namespaceURI** Namespace-URI.

## Rückgabewert

true, wenn namespaceURI der Standard-Namespace ist, andernfalls false.
