# createWorkflowFromModelId

Erstellt einen auf einer Vorlage basierenden Kampagnen-Workflow.

```text
Number workflowId = CreateWorkflowFromModelId ( Number modelId, XML operationPlanning )
```

## Parameter

**modelId** Kennung der Workflow-Vorlage

**operationPlanning** Kampagnenzeitplan

## Rückgabewert(e)

**workflowId** Kennung der erstellten Instanz

## Funktionen

**Schema:** [nms:operation](s-nms-operation.md)

**static:**

Ja
