# GetInputValues

Sucht die möglichen Werte für ein Eingabefeld in einem Formular

```text
XML options = GetInputValues ( String schema, XML input )
```

## Parameter

**schema** Bearbeitungsschema der Umfrage.

**input** Eingabefeld.

## Rückgabewert(e)

**options** Mögliche Werte für diese Eingabezone.

## Funktionen

**Schema:** [xtk:abstractForm](s-xtk-abstractform.md)

**static:**

Ja
