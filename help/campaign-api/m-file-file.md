# Datei

Erstellt ein neues Objekt, das mit einer Datei verknüpft ist.

```text
File (filename)
```

## Parameter

**filename** Der Name der Datei, die gelesen oder erstellt werden soll.

## Rückgabewert

Keine.

## Bemerkungen

Beispiel:

```javascript
var f = new File("/tmp/file.txt")
```
