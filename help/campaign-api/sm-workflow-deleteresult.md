# Ergebnis löschen

Löscht die Ergebnisse von einer oder mehreren Aktivitäten.

```text
DeleteResult ( String workflowId, String activityName )
```

## Parameter

**workflowId** Kennung oder interner Name des Workflows.

**activityName** Name der Aktivität(en), deren Ergebnisse gelöscht werden sollen

## Rückgabewert(e)

Keine.

## Funktionen

**Schema:** [xtk:workflow](s-xtk-workflow.md)

**static:**

Ja
