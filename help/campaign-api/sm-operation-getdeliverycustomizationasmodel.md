# GetDeliveryCustomizationAsModel

Kopiert ausgewählte Vorlagen für Personalisierungsfelder.

```text
XML parentOut = GetDeliveryCustomizationAsModel ( XML selection, XML parentIn )
```

## Parameter

**selection** Element mit den ausgewählten Vorlagenkennungen

**parentIn** Element mit den vorhandenen Personalisierungen

## Rückgabewert(e)

**parentOut** Gibt das Element mit den hinzugefügten neuen Vorlagen zurück.

## Funktionen

**Schema:** [nms:operation](s-nms-operation.md)

**static:**

Ja
