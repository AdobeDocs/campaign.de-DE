# getUTF8Parameter

Gibt den Wert (in UTF-8 codiert) eines Parameters der Abfrage zurück.

```text
getUTF8Parameter (name)
```

## Parameter

**name** Parametername.

## Rückgabewert

Der Wert des angeforderten Parameters.

## Funktionen

**Methode der Klasse:** [HttpServletRequest](c-httpservletrequest.md)

**Verfügbar in:**

* JSSP
* WEBAPP
