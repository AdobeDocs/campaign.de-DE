# ExportList erstellen

Erstellt die Liste, in die die Entitäten des Warenkorbs exportiert werden

```text
Number listId = CreateExportList ( String label, Number folderId )
```

## Parameter

**label** Bezeichnung der Liste

**folderId** ID des Ordners, in dem die Liste erstellt wird (0 für den Standardordner).

## Rückgabewert(e)

**listId** ID der neu erstellten Liste

## Funktionen

**Schema:** [xtk:olapCube](s-xtk-olapcube.md)

**static:**

Ja
