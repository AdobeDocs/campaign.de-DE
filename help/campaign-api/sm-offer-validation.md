Angebotsvalidierung

```text
Validation ( Number offerId, Number type, XML offerSpaces, Boolean refused, String comment )
```

## Parameter

**offerId** Angebots-ID

**type** Validierungstyp (Zielgruppenbestimmung=0, Inhalt=1)

**offerSpaces** Zu validierende Platzierungen

**abgelehnt** Ablehnung der Eignungsgenehmigung
