# Priorisieren von Protokollen

Priorisiert Versandlogs einer Versandliste

```text
PrioritizeLogs ( Number id, XML deliveries, String logTable )
```

## Parameter

**id** Eindeutige Prioritätskennung

**Sendungen** Liste der zu berücksichtigenden Sendungen

**logTable** Tabelle mit allen Protokollmeldungen

Keine.
