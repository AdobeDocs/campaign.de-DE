# mkdir

Erstellt ein Verzeichnis mit dem Pfad des aktuellen [Datei](c-file.md)-Objekts.

```text
mkdir ()
```

## Parameter

Keine.

## Rückgabewert

Keine.

## Bemerkungen

Erstellt bei Bedarf auch Zwischenordner. Im Falle eines Fehlers wird eine Ausnahme ausgelöst.
