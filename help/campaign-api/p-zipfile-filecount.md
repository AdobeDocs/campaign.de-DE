# fileCount

Gibt die Anzahl der Dateien im Archiv aus

```text
fileCount
```

## Bemerkungen

Das Archiv muss mit der Methode ⌐[open()](m-zipfile-open.md) geöffnet worden sein, bevor diese Methode verwendet werden kann. Andernfalls wird eine Ausnahme ausgelöst.
