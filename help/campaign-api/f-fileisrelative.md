# fileIsRelative

Gibt an, ob ein Dateiname ein relativer Name ist.

```text
fileIsRelative (fileName)
```

## Parameter

**fileName** Dateiname.

## Rückgabewert

Wahr, wenn der Dateiname relativ ist.

* Content-Management
* Versandeigenschaften
* Typologieregel
