# getAttributeNS

Gibt den Attributwert zurück.

```text
getAttributeNS (namespaceURI, localName)
```

## Parameter

**namespaceURI** URI des Attribut-Namespace.

**localName** Attributname.

## Rückgabewert

Attributtextwert.
