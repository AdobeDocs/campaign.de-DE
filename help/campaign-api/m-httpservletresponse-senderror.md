# sendError

Gibt eine Fehlerantwort mit dem als Parameter übergebenen Fehlercode zurück.

```text
sendError (errorCode)
```

## Parameter

**errorCode** Der HTTP-Fehlercode.

## Rückgabewert

Keine.

## Funktionen

**Methode der Klasse:** [HttpServletResponse](c-httpservletresponse.md)

**Verfügbar in:**

* JSSP
* WEBAPP
