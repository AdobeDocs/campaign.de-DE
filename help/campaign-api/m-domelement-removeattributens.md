# removeAttributeNS

Löschen eines Attributs.

```text
removeAttributeNS (namespaceURI, localName)
```

## Parameter

**namespaceURI** URI des Attribut-Namespace.

**localName** Attributname.

## Rückgabewert

Keine.

## Bemerkungen

Die Methode hat keine Auswirkung, wenn das Element kein Attribut dieses Namens aufweist.
