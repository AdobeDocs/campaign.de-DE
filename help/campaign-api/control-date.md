# Datum

Mit einer Steuerung vom Typ Datum können Sie ein Datum eingeben.

![Datumseinstellung](assets/date.925e5185.png)

## Eigenschaften

**backColor - Zeichenfolge** Hintergrundfarbe (btnshadow, weiß).

**border - string** Ändert den Rahmenstil während des Steuerelements (solid, double, inset, outset, none).

**font-size - integer** Ändert die Schriftgröße.

**label - Zeichenfolge** Zugeordnete Bezeichnung.

**nolabel - Boolesch** Blendet die zugehörige Beschriftung aus.

**readOnly - boolean** Erzwingt, dass das Steuerelement schreibgeschützt ist.

**erforderlich - boolesch** Das Feld ist obligatorisch.

## Bemerkungen

Sie können dieses Steuerelement verwenden, um auf ein Feld vom Typ Datum/Uhrzeit zu verweisen und nur den Datums- bzw. Uhrzeitteil zu bearbeiten. Der Zeitteil wird auf Null zurückgesetzt.
