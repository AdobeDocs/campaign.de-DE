# Bericht generieren und speichern

Erzeugt einen Bericht vom Server ausgehend und speichert ihn in der Datenbank

```text
XML result = GenerateAndSaveReport ( String reportName, XML context )
```

## Parameter

**reportName** Interner Berichtsname

**context** Berichtskonfiguration

## Rückgabewert(e)

**result** Eindeutige Kennung und Datensatzdatum

## Funktionen

**Schema:** [xtk:report](s-xtk-report.md)

**static:**

Ja
