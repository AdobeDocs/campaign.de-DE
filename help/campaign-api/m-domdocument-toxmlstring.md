# toXMLString

Konvertiert das XML-Dokument in eine Zeichenfolge.

```text
toXMLString (format)
```

## Parameter

**format** Ein boolescher Wert zum Formatieren des XML-Dokuments.

## Rückgabewert

Keine.

## Bemerkungen

Diese Methode fügt das Prolog hinzu, im Gegensatz zur Methode mit demselben Namen für Elemente.
