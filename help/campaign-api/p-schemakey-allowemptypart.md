# allowEmptyPart

Gibt „true“ zurück, wenn Felder des Schlüssels leer sein können (mindestens eines der Felder muss eingegeben werden).

```text
allowEmptyPart
```

## Funktionen

**Eigenschaft der Klasse:** [SchemaKey](c-schemakey.md)

**Schreibgeschützt:**

Ja
