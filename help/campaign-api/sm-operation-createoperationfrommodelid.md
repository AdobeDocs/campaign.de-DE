# CreateOperationFromModelId

Erstellt eine auf einer Vorlage basierende Kampagne.

```text
Number operationId = CreateOperationFromModelId ( Number modelId, XML operationPlanning )
```

## Parameter

**modelId** Kennung der Kampagnenvorlage

**operationPlanning** Kampagnenzeitplan

## Rückgabewert(e)

**operationId** Kennung der erstellten Instanz

## Funktionen

**Schema:** [nms:operation](s-nms-operation.md)

**static:**

Ja
