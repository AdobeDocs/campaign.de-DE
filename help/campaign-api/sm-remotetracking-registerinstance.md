# RegisterInstance

Ermöglicht die Validierung einer Trackinginstanz

```text
RegisterInstance ( String instanceName, String dbId, String lang )
```

## Parameter

**instanceName** Name der zu validierenden Instanz

**dbId** Datenbankkennung des Kunden, der einen Versand durchführt

**lang** Instanzsprache

## Rückgabewert(e)

Keine.

## Funktionen

**Schema:** [nms:remoteTracking](s-nms-remotetracking.md)

**static:**

Ja
