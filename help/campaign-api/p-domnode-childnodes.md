# childNodes

Gibt die Liste der untergeordneten Knoten in Form einer Tabelle zurück.

```text
childNodes
```

## Bemerkungen

Diese Eigenschaft erstellt für jeden Zugriff eine neue Tabelle. Daher ist es besser, die Tabelle in einer lokalen Variablen zu speichern, anstatt mehrmals auf die Eigenschaft zuzugreifen.
