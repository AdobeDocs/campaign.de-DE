# insertData

Fügt eine Zeichenfolge an einer bestimmten Position in den Text ein.

```text
insertData (offset, arg)
```

## Parameter

**offset** Einfügeposition (0 für das erste Zeichen).

**arg** String der einzufügenden Zeichen.

## Rückgabewert

Keine.
