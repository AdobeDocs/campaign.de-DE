# EnumerationValue (Klasse)

Stellt die Definition eines Auflistungswerts dar.

## Eigenschaften

| Eigenschaft | Beschreibung |
| --- | --- |
| [label](p-enumerationvalue-label.md) | Gibt eine Zeichenfolge zurück, die die kurze Beschreibung des aktuellen Auflistungswerts enthält. |
| [description](p-enumerationvalue-description.md) | Gibt eine Zeichenfolge zurück, die die Beschreibung des aktuellen Auflistungswerts enthält. |
| [value](p-enumerationvalue-value.md) | Gibt eine Zeichenfolge zurück, die den Wert des aktuellen Auflistungswerts angibt. |
| [name](p-enumerationvalue-name.md) | Gibt eine Zeichenfolge zurück, die den Namen des aktuellen Auflistungswerts angibt. |
| [Bild](p-enumerationvalue-image.md) | Gibt eine Zeichenfolge zurück, die den Namen des Bildes des aktuellen Auflistungswerts angibt. |
| [enabledIf](p-enumerationvalue-enabledif.md) | Gibt eine Zeichenfolge zurück, die die Gültigkeitsbedingungen des aktuellen Auflistungswerts angibt. |
