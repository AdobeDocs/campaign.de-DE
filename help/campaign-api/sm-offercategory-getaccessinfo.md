# GetAccessInfo

Gibt die geerbten Eigenschaften in Bezug auf den anonymen Modus aus.

```text
[ Boolean anonymous, Boolean parentAnonymous ] = GetAccessInfo ( Number categoryId )
```

## Parameter

**categoryId** Kategorie-ID

## Rückgabewert(e)

**anonym** Gibt an, ob die Kategorieangebote anonym sind oder nicht

**parentAnonymous** Gibt an, ob die Angebote der übergeordneten Kategorie anonym sind

## Funktionen

**Schema:** [nms:offerCategory](s-nms-offercategory.md)

**static:**

Ja
