# replaceChild

Ersetzen Sie einen Knoten.

```text
replaceChild (newChild, oldChild)
```

## Parameter

**newChild**-Knoten zum Einfügen.

**oldChild**-Knoten, der ersetzt werden soll.

## Rückgabewert

Knoten ersetzt.
