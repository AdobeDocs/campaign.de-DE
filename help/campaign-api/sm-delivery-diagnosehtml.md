# DiagnoseHTML

Startet die Prüfung des HTML-Inhalts

```text
XML diagnostic = DiagnoseHTML ( String htmlContent, Number format )
```

## Parameter

**htmlContent** HTML-Inhalt, der überprüft werden soll

**format** Das Mail-Format

## Rückgabewert(e)

**diagnostic** Gibt die Diagnose zurück.

## Funktionen

**Schema:** [nms:delivery](s-nms-delivery.md)

**static:**

Ja
