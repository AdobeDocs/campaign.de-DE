# instanceUploadDir

Vollständiger Pfad des &#39;upload&#39;-Verzeichnisses für die Instanz, in der das Script ausgeführt wird.

```text
instanceUploadDir
```

## Bemerkungen

Der zurückgegebene Wert berücksichtigt eine mögliche Überlastung des Upload-Verzeichnisses in den Server-Parametern.
