# DigestStrSha512

Berechnet den SHA-512-Hash einer Zeichenfolge. Die Zeichenfolge wird vor der Berechnung automatisch in UTF-8 codiert.

```text
digestStrSha512 (string)
```

## Parameter

**string** Die Zeichenfolge, in der der Hash berechnet werden soll.

## Rückgabewert

Der SHA-512-Hash der als Parameter übergebenen Zeichenfolge.
