# ausführen

Alias des Befehls „execute“. Diese Funktion ist veraltet. Verwenden Sie [execute()](m-dbengine-execute.md)

```text
exec (command [, value1, ... ])
```

## Parameter

**Befehl** SQL-Befehl.

**value1, …** Variablen des Befehls.

## Rückgabewert

Die Anzahl der aktualisierten oder eingefügten Aufzeichnungen, falls dies für den ausgeführten Befehl gilt, wenn nicht null.
