# submitDeliveryById

Erstellung und Unterbreitung eines Versands von einer Vorlage ausgehend (durch die interne Kennung bezeichnet)

```text
Number deliveryId = SubmitDeliveryById ( Number scenarioId, XML content )
```

## Parameter

**scenarioId** Vorlagenkennung

**content** XML-Inhalt, der der Vorlage hinzugefügt werden soll

## Rückgabewert(e)

**deliveryId** XML-Inhalt, der der Vorlage hinzugefügt werden soll

## Funktionen

**Schema:** [nms:delivery](s-nms-delivery.md)

**static:**

Ja
