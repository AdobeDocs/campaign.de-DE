# JavaScript-Ausnahmen

Wenn ein Fehler auftritt, wird das ausgeführte Skript standardmäßig unterbrochen. Ab Version 4.05 können Sie jedoch Fehler erfassen und verarbeiten, um die Skriptverarbeitung fortzusetzen.

Die von Adobe Campaign ausgelösten Ausnahmen sind Fehler-Codes ( `Number` Typ ).

## Beispiel

In diesem Beispiel wird versucht, eine Webseite von einer ungültigen Adresse wiederherzustellen, und es wird eine Ausnahme von der Funktion [getUrl()](f-geturl.md) ausgelöst.

```javascript
try
{
  var url = "xx:/invalid-url"
  getUrl(url)
}
catch(e)
{
  logInfo("Can't get page content: " + url )
  logInfo("Error number: " + e )
}

  
```
