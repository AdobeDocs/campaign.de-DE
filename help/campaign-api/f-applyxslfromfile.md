# applyXslFromFile

Transformiert ein XML-Dokument mithilfe eines XSL-Stylesheets.

```text
applyXslFromFile (xslEntity, filename)
```

## Parameter

**xslEntity** Der Name des in der Datenbank gespeicherten XSL-Stylesheets.

**filename** Der Name der umzuwandelnden XML-Datei.

## Rückgabewert

Das XML-Dokument in Form einer Zeichenfolge nach der Umwandlung.
