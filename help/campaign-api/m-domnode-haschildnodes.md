# hasChildNodes

Testet, ob der Knoten mindestens einen Unterordner hat.

```text
hasChildNodes ()
```

## Parameter

Keine.

## Rückgabewert

true, wenn der Knoten mindestens ein untergeordnetes Element hat, andernfalls false.
