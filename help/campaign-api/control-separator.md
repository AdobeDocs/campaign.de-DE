# Trennzeichen

Ein Trennzeichen mit einem Text und einem Bild anzeigen.

![Separator-Steuerelement](assets/separator.70317a27.png)

## Eigenschaften

**richtung - Zeichenfolge** Standardmäßig horizontal.

**img - Zeichenfolge** Zugehöriges Bild.

**label - Zeichenfolge** Anzuzeigender Text.

## Bemerkungen

Beispiel:

```xml
      <static type="separator" label="Please enter your name here."/>

<static type="separator">Please enter your name here.</static>
```
