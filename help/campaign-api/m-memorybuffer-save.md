# speichern

> Warnung:
>
> Der Zugriff über Datei-APIs ist auf die **var**, **sftp** und temporären Ordner von Adobe Campaign beschränkt.

Speichert den Inhalt des Puffers in eine Datei.

```text
save (filename)
```

## Parameter

**filename** Der Name der zu speichernden Datei.

## Rückgabewert

Keine.
