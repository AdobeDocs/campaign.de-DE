# ComputeUrl

Erzeugt die URL zum Zugriff auf die pURL

```text
[ String url, String exampleUrl ] = ComputeUrl ( XML purl )
```

## Parameter

**purl** Die aktuelle pURL.

## Rückgabewert(e)

**url** URL (technisch)

**exampleUrl** URL mit fiktiven Daten (zur Anzeige)

## Funktionen

**Schema:** [nms:purl](s-nms-purl.md)

**static:**

Ja
