# UpdateLevelName

Aktualisiert den internen Ebenennamen in Abhängigkeit vom Ausdruck.

```text
XML result = UpdateLevelName ( XML level, XML dimension )
```

## Parameter

**level** Zu ändernde Ebene

**dimension** Übergeordnete Dimension der Ebene

## Rückgabewert(e)

**result** Geänderte Ebene

## Funktionen

**Schema:** [xtk:olapDimension](s-xtk-olapdimension.md)

**static:**

Ja
