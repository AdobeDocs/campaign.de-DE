# Werte und Aliase wechseln

Konvertierung eines Werts in Alias und umgekehrt.

```text
SwitchValuesAndAliases ( XML enums, String mode )
```

## Parameter

**enums** Auflistung der zu konvertierenden Auflistungen.

**mode** Konvertierungsmodus: Muss &#39;ValuesToAliases&#39; oder &#39;AliasesToValues&#39; sein.

## Rückgabewert(e)

Keine.

## Funktionen

**Schema:** [xtk:enum](s-xtk-enum.md)

**static:**

Ja
