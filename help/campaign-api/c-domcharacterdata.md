# DOMCharacterData (Klasse)

Ein Knoten, der nur Text enthält. Dabei kann es sich um einen Textknoten oder einen Kommentar handeln.

## Methoden

| Methode | Beschreibung |
| --- | --- |
| [substringData](m-domcharacterdata-substringdata.md) | Extrahieren Sie einen Teil des Textes. |
| [appendData](m-domcharacterdata-appenddata.md) | Fügen Sie dem Text eine Zeichenfolge hinzu. |
| [insertData](m-domcharacterdata-insertdata.md) | Fügt eine Zeichenfolge an einer bestimmten Position in den Text ein. |
| [deleteData](m-domcharacterdata-deletedata.md) | Löscht einen Teil des Textes. |
| [replaceData](m-domcharacterdata-replacedata.md) | Ersetzt einen Teil des Textes. |

## Eigenschaften

| Eigenschaft | Beschreibung |
| --- | --- |
| [data](p-domcharacterdata-data.md) | Textwert des Knotens. |
| [length](p-domcharacterdata-length.md) | Anzahl der Zeichen im Knoten. |
